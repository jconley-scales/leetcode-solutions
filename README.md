# LeetCode Solutions

My solutions to LeetCode problems in JavaScript, as I practice data structures and algorithms.

## Solutions

- **Two Sum** — hash map to find each number's partner in one pass. O(n) time, O(n) space.
- **Contains Duplicate** — hash set to check for repeats. O(n) time, O(n) space.
- **Valid Anagram** — counting letters with two hash maps. O(n) time.
- **Valid Parentheses** — stack to match brackets. O(n) time, O(n) space.
